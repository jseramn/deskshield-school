## Suggested Devpost short description

Hotel front desks in LatAm are targeted by phishing campaigns that impersonate reservations, invoices, and job applicants. DeskShield is a bilingual (EN/ES) reception-inbox trainer with decide/feedback loops, a 5-minute incident playbook, and a manager report card — built for small hotels that lack role-specific security practice.
